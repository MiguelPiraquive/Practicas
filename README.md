# 🏥 SIGET-HC

**Sistema de gestión desarrollado como proyecto de práctica profesional / proyecto de grado en el sector salud.**

Aplicación web full-stack con backend en **Django (Python)**, frontend en **JavaScript** y una **pasarela de WhatsApp** para comunicación/notificaciones. El repositorio incluye la documentación de ingeniería del proyecto: arquitectura, requerimientos (IEEE-830), cronograma y manual de usuario.

## ✨ Componentes

- ⚙️ **Backend** — API y lógica de negocio (Django).
- 🖥️ **Frontend** — interfaz de usuario.
- 💬 **WhatsApp Gateway** — pasarela de mensajería.
- 📚 **Documentación** — arquitectura, requerimientos (IEEE-830), cronograma y manual de usuario.

## 🛠️ Stack

`Python` · `Django` · `JavaScript` · `WhatsApp API` · documentación de ingeniería de software.

## 📁 Estructura

```text
backend/           # Django
frontend/          # Interfaz de usuario
whatsapp-gateway/  # Pasarela de WhatsApp
*.md / *.pdf       # Documentación (arquitectura, requerimientos, cronograma, manual)
```
